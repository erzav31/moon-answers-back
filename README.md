Entry for the [The Moon Finally Answers Back](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1) bounty on make.fun.

`main.ts` writes a single line (148 characters) to `/output/entry.txt` —
the Moon, after 312 wishes and zero kept promises, finally answers by
granting the one whispered at 3 a.m.: the promise about finally leaving him.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network. Node 22+.
